# Memtree Pluggable Store Backend Design

**Date:** 2026-06-01  
**Phase:** 7 (EdgeLite integration)  
**Scope:** memtree MCP server (`mcp/` package inside the memtree repo)

---

## Goal

Replace the hard-wired `bun:sqlite` store with a pluggable backend abstraction. The initial release ships two backends — SQLite (existing) and EdgeLite/PGlite (new). All callers update to use the unified `StoreBackend` interface. Both backends are tested against a shared contract suite.

---

## File Layout

```text

      edgelite/

```

**Callers updated:** `server.ts`, `ingest.ts`, all `tools/*.ts`, all `walkers/*.ts`.

## StoreBackend Interface

Defined in `store/interface.ts`. All methods return `Promise<T>`.

```typescript
export interface StoreBackend {
  // Nodes
  insertNode(id: string, params: InsertNodeParams): Promise<void>;
  getNode(id: string): Promise<MemtreeNode | null>;
  updateNodeStatus(id: string, status: NodeStatus): Promise<void>;
  getNodeBySourceUri(uri: string): Promise<MemtreeNode | null>;
  getNodeByContentHash(hash: string): Promise<MemtreeNode | null>;
  listChildren(parentId: string, status?: NodeStatus): Promise<MemtreeNode[]>;
  getOrCreateSessionNode(sessionId: string): Promise<MemtreeNode>;
  markStaleByFilePath(filePath: string, mtime: number): Promise<void>;
  countPendingNodes(): Promise<number>;
  getPendingNodes(limit?: number): Promise<MemtreeNode[]>;
  getLiveFileChunks(cutoffMs: number): Promise<MemtreeNode[]>;
  getStaleNodes(olderThanMs: number): Promise<MemtreeNode[]>;
  getSupersededNodes(olderThanMs: number): Promise<MemtreeNode[]>;
  pruneNode(id: string): Promise<void>;
  // Edges
  insertEdge(edge: Omit<MemtreeEdge, 'created_at'>): Promise<void>;
  getNeighbors(nodeId: string, edgeKinds?: EdgeKind[]): Promise<MemtreeNode[]>;
  getEdgesFrom(srcId: string): Promise<MemtreeEdge[]>;
  // Search
  searchKeyword(query: string, filters?: Filters, limit?: number): Promise<MemtreeNode[]>;
  searchSemantic(vector: number[], filters?: Filters, limit?: number): Promise<MemtreeNode[]>;
  // Lifecycle
  close(): Promise<void>;
}

export interface InsertNodeParams {
  parent_id: string | null;
  kind: NodeKind;
  source_uri: string | null;
  content: string;
  content_hash: string;
  status: NodeStatus;
  mtime: number;
  truncated: number;       // 0 | 1 — kept as number for backward compat
  original_bytes: number;
  metadata: string;        // JSON blob
  summary?: string | null;
}
```

**EdgeLite adapter translations** (internal to `backends/edgelite/`):

- `parent_id` → `parent` (link field)
- `src_id` / `dst_id` → `src` / `dst` (link fields)
- `metadata: string` → `JSON.parse(metadata)` for the `json` column
- `truncated: 0 | 1` → `truncated: boolean`

## SDL Schema (`mcp/dbschema/schema.esdl`)

```sdl
scalar type NodeKind extending enum<
  session, file_chunk, tool_output, summary, note,
  observation, web_chunk, prompt, thinking, response
>;
scalar type NodeStatus extending enum<pending, live, stale, superseded, pruned>;
scalar type EdgeKind extending enum<
  derived_from, references, summarizes, supersedes, follows
>;

type Node {
  required kind:           NodeKind;
  required status:         NodeStatus  { default := 'pending' };
  required content:        str         { default := '' };
  required content_hash:   str         { default := '' };
  required mtime:          int64       { default := 0 };
  required created_at:     int64;
  required updated_at:     int64;
  required truncated:      bool        { default := false };
  required original_bytes: int64       { default := 0 };
  source_uri:              str;
  metadata:                json        { default := '{}' };
  summary:                 str;
  parent:                  Node;

  index fts on (.content);
}

type Edge {
  required src:        Node;
  required dst:        Node;
  required kind:       EdgeKind;
  required created_at: int64;

  constraint exclusive on ((.src, .dst, .kind));
}
```

Vector column is deferred to Phase 8 (see phase-8 plan for `searchSemantic` wiring).

## Config Extension

### `store/types.ts` additions

```typescript
export type BackendKind = 'sqlite' | 'edgelite';

export interface BackendConfig {
  kind: BackendKind;     // env: MEMTREE_BACKEND
  schemaPath?: string;   // edgelite only — env: MEMTREE_SCHEMA_PATH
}

// MemtreeConfig gains:
backend?: BackendConfig;
```

### Default

```typescript
// config.ts
export const DEFAULT_CONFIG: MemtreeConfig = {
  // ...existing fields...
  backend: { kind: 'sqlite' },
};
```

### Env var resolution (applied after JSON merge in `loadConfig`)

```typescript
if (process.env.MEMTREE_BACKEND)
  merged.backend = { ...merged.backend, kind: process.env.MEMTREE_BACKEND as BackendKind };
if (process.env.MEMTREE_SCHEMA_PATH)
  merged.backend = { ...merged.backend, schemaPath: process.env.MEMTREE_SCHEMA_PATH };
```

Resolution order (last wins): defaults → `~/.memtree/config.json` → `./.memtree/config.json` → env vars.

## Backend Factory

```typescript
// store/index.ts
export async function createBackend(
  config: BackendConfig,
  dbPath: string,
): Promise<StoreBackend> {
  if (config.kind === 'edgelite') {
    const schemaPath = config.schemaPath ?? path.join(process.cwd(), 'dbschema/schema.esdl');
    return createEdgeliteBackend(dbPath, schemaPath);
  }
  return createSqliteBackend(dbPath);
}
```

## SQLite Backend

`backends/sqlite/index.ts` wraps the current `db.ts` + `nodes.ts` + `edges.ts` logic. Each function wraps its synchronous result in `Promise.resolve()`. `searchKeyword` uses FTS5. `searchSemantic` uses the existing `nodes_vec` table. `close()` calls `closeDb(db)`.

---

## EdgeLite Backend

`backends/edgelite/index.ts` calls `openDb(dbPath, schemaPath, { autoMigrate: true })` from the `edgelite` package. All query methods use the generated `e.*` builder from `dbschema/edgelite.ts`. `searchSemantic` throws `new Error('NotImplemented: searchSemantic requires Phase 8 vector wiring')`. `close()` calls edgelite's `closeDb`.

---

## Caller Migration

`server.ts`:

```typescript
// before
const db = openDb(dbPath);
// after
const store = await createBackend(config.backend ?? { kind: 'sqlite' }, dbPath);
```

Shutdown: `closeDb(db)` → `await store.close()`.

All tool and walker function signatures: `db: Database` → `store: StoreBackend`. All call sites add `await`. Tool functions that are currently synchronous become `async`.
