# Installation

## Requirements

- Node.js `>= 22`
- A package manager: pnpm (recommended), npm, or bun

## Install

**pnpm (recommended)**

```bash
pnpm add edgelight
```

**npm**

```bash
npm install edgelight
```

**bun**

```bash
bun add edgelight
```
